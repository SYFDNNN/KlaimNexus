# Public Portfolio Scope

This repository is intentionally a **showcase**, not the full KlaimNexus source distribution.

## Published here

- Product overview and architecture
- Prototype screenshots
- Model-evaluation summary
- Privacy and governance notes
- Synthetic example payload
- Team/project contribution summary

## Intentionally withheld

- Flask/backend implementation
- Similarity and priority-scoring implementation
- Full frontend source
- Trained `.joblib` model artifacts
- Model feature/configuration artifacts
- Training and inference notebooks
- Synthetic dataset generator internals
- Raw/interim/processed datasets
- Internal experiment reports and threshold-search outputs
- SQLite state/database
- Local Git history from the private development repository

## Why

The project is being shown to demonstrate product thinking, ML experimentation, system design, and implementation maturity while protecting implementation details and reusable project IP.

Selected code or a guided demo can be shared privately during recruitment or technical review when appropriate.
